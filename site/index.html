The work only a human can do, longest lead first

  • Clocks: external waits, each with a lead time you cannot compress, projected from the day it started.
  • Your desk: self-serve tasks like a GUI build or a restore drill, smallest first.
  • Start today: the one item that buys back the most calendar time, with the arithmetic printed.

Slack, computed

Each clock's slack is the launch's longest chain minus its own. Zero slack means every day of delay lands on the launch date.

Running clocks count down

A D-U-N-S request started three weeks ago with a 5–30 day lead has at most 9 days left, and the report says so.

Unknowns stay visible

A clock with no lead days is listed as unranked, so nobody mistakes "unknown" for "instant".

The other half

Done means someone checked

Every story has a Done when that a stranger could verify: a command that exits 0, a file holding a value, a screen showing a thing. /lc:done runs that check before it ticks anything off.

Day to day

The loop a session runs

  1. /lc:groom

    Files a new item with real acceptance criteria. /lc:plan files a whole backlog from a design doc.

  2. /lc:next

    Hands out the first Ready story a session can do, and reads its traps aloud.

  3. /lc:start

    Claims it: sets the status, cuts a branch, binds the session to the story.

  4. /lc:done

    Runs the check, ships through a PR, and promotes every story that was waiting on this one.

Two hooks keep it honest. At session start, the agent is told which story it is bound to and the repo's standing warnings. A session with a claimed story is asked once before it exits.

Quickstart

Five steps. Three happen in a browser.

About five minutes if Notion is already connected to Claude Code, about half an hour from nothing. The orange steps are ones no script can do for you.

Terminal

Set the machine up

Checks claude, python3, git and gh, adds the Notion MCP server and installs the plugin. Run it bare first: it's a dry run that changes nothing.

git clone https://github.com/peter3605/launch-control.git && cd launch-control && ./setup.sh --apply
Browser

Authorise Notion

Run /mcp inside Claude Code and finish Notion's sign-in. Setup configured the connector. This step grants it access.

Browser

Share the page the board will live under

In Notion, open the page, then ··· → Add connections → Notion. Skip this and the connector works but returns nothing, which is the most common broken setup.

Claude Code

Turn on auto-update

/plugin → Marketplaces → launch-control → Enable auto-update. Third-party marketplaces don't update on their own.

Claude Code, in your repo

Build the board and pull the first story

The board starts empty, so file something before asking for work.

/lc:init
/lc:groom Request SES production access
/lc:next
